# APJ---Acelerador-de-Produtividade-Jovem
APJ (Acelerador de Produtividade Jovem) é uma plataforma de onboarding desenvolvida para centralizar informações, documentações e acessos de novos estagiários. Possui checklist de tarefas, barra de progresso, glossário e conteúdos sobre ferramentas, ambientes e processos da empresa.
